# Agent Change Inspector (AI Diff Guard & Snapshot Engine)

> **Интеллектуальная система защиты проекта, версионирования и инспекции правок AI-агентов для Visual Studio Code.**

Расширение создано для разработчиков, активно использующих инструменты генерации кода и автономных AI-агентов (**Google Antigravity, Claude Code, Aider, Cursor, GitHub Copilot CLI, Windsurf** и др.). 

Когда внешний агент модифицирует десятки файлов, разработчик теряет контроль: непонятно, какие именно файлы были затронуты, что в них изменилось, удалил ли агент что-то лишнее и как быстро вернуться к рабочей версии.

**Agent Change Inspector** берет проект под круглосуточную охрану:
1. **Мгновенно открывает измененные файлы** во вкладках с закреплением и фокусировкой на первых измененных строках.
2. **Мягко подсвечивает измененные строки** прямо в коде, на полях (Gutter) и на полосе прокрутки.
3. **Сохраняет физические копии (снэпшоты) файлов «ДО правок»** в структурированный каталог `.agent-inspector/snapshots/`, позволяя в любой момент восстановить файл или шаг.
4. **Хранит историю и деревья метаданных** в `.agent-inspector/tree/` (статусы: `modified`, `added`, `deleted`, `moved`, `copied`, диапазоны строк).
5. **Предоставляет двухпанельный проводник** (Дерево папок / Плоский список) с цветными статусами файлов.
6. **Полная независимость от Git CLI**: работает в любых вложенных каталогах, монорепозиториях, проектах со своими подмодулями или вовсе без Git.
7. **Защита от лавины окон**: таймер 200 мс блокирует открытие вкладок при массовом копировании или распаковке файлов.
8. **Управляет умным файлом исключений** `.agent-inspector/.agentignore`, автоматически собирая все `.gitignore` проекта.

## 🧩 Подробное описание подсистем и модулей

### 1. `ChangeDetector` — Детектор изменений и защита от лавин
* **Файловый наблюдатель**: Отслеживает события `vscode.workspace.createFileSystemWatcher('**/*')` и `vscode.workspace.onDidSaveTextDocument`. Ловит правки из любого источника (Python, Explorer, bash, терминал).
* **Таймер-защита от копирования и перемещения (< 200 мс)**:
  * Если события файловой системы происходят с интервалом менее 200 мс (массовое копирование, распаковка), расширение блокирует автоматическое открытие вкладок, предотвращая зависание VS Code.
  * Сами изменения корректно заносятся в дерево и снэпшоты.
* **Безусловная защита от рекурсивных циклов**:
  * Служебные папки `/.git/`, `/node_modules/`, `/.agent-inspector/`, `/.vscode/`, `/dist/` отсекаются немедленно.
* **Дебаунс и пакетирование**:
  * Изменения собираются и обрабатываются пакетами с задержкой 300 мс.

---

### 2. `BaselineManager` & `DiffHelper` — Автономный Diff без вызова Git
* **Baseline проекта**: При старте сканирует проект и сохраняет исходное состояние текстовых файлов.
* **Независимый diff**: Использует построчное сравнение на TypeScript/JS, вычисляя точные диапазоны строк (`hunks`), количество добавленных и удаленных строк, номер первой измененной строки.
* **Поддержка любых репозиториев**: Полностью решена проблема вложенных каталогов со своими `.git` или монорепозиториев — расширение не вызывает `git status` / `git diff`, а работает напрямую с файлами.
* **Защита**: Бинарные файлы (по расширениям и проверке на нулевой байт `\0`) и файлы более 2 МБ исключаются из построчного diff-анализа.
* **Поддержка Ctrl+Z**: Если файл возвращен пользователем к состоянию baseline, он автоматически убирается из активных правок.

---

### 3. `StorageManager` — Разделение ответственности хранения
* **Структура каталога `.agent-inspector/`**:
  ```text
  .agent-inspector/
    ├── .gitignore          # Содержит '*\n' — полностью защищает каталог от коммита в Git
    ├── .agentignore        # Правила исключений для расширения
    ├── tree/               # Деревья метаданных (JSON)
    │   ├── current.json    # Активные незафиксированные изменения
    │   └── 2026_10_29_14_23_07.json # Зафиксированный шаг (манифест изменений)
    └── snapshots/          # Физические резервные копии файлов
        └── 2026_10_29_14_23_07/
            └── src/
                └── index.ts # Оригинал файла ДО изменений данного шага
  ```
* **Точные снэпшоты**: При первой модификации файла в шаге его исходное состояние из baseline сохраняется в `snapshots/<folderName>/<relativeName>`.
* **Восстановление**:
  * Для измененных или удаленных файлов: точное копирование из папки снимка.
  * Для созданных файлов (`added`): удаление файла с диска при откате.

---

### 4. `HistoryManager` — Шаги промптов и ручная фиксация
* **Текущий шаг (`currentTurnChanges`)**: Накапливает активные изменения файлов.
* **Ручная фиксация шага по кнопке**:
  * По умолчанию шаг фиксируется разработчиком вручную через кнопку `$(archive)` в заголовке панели, в статус-баре или по команде `agentDiff.archiveCurrentStep`.
  * При фиксации создается манифест в `tree/<folderName>.json`, базовая линия обновляется, а текущий список очищается для следующего шага.
* **Опциональный авто-кулдаун**: Можно включить в настройках `agentDiff.autoArchive: true` с таймером бездействия (по умолчанию 8 секунд).

---

### 5. `DiffPresenter` — Умное открытие вкладок
* **Встроенный Diff со снимком**:
  * Вызывает нативную команду `vscode.diff(snapshotUri, currentUri, title)`, открывая двухпанельное сравнение VS Code без участия Git.
* **Защита от лавины вкладок (`maxAutoOpenFiles`)**:
  * Ограничивает авто-открытие первыми $N$ файлами (по умолчанию 3).
* **Постоянные вкладки (`keepEditor`)**:
  * Все вкладки закрепляются как постоянные (без курсива предпросмотра).

---

### 6. `DecorationManager` — Полоски в Gutter и подсветка кода
* **Gutter-маркеры (SVG)**:
  * Зеленая полоса в поле номеров строк для добавленных и измененных строк.
  * Красный маркер-треугольник для удаленных строк.
* **Фон строк**: Мягкая полупрозрачная подсветка строк в редакторе (`diffEditor.insertedLineBackground`).
* **Overview Ruler**: Метки на полосе прокрутки и миникарте для быстрой навигации.

---

### 7. `AgentChangesTreeProvider` — Проводник правок
* **Двойное размещение**:
  1. Вкладка на Activity Bar («Правки ИИ»).
  2. Панель в Explorer слева.
* **Режимы отображения (`treeViewMode`)**:
  * **Иерархическое дерево (`tree`)**: полноценная древовидная структура с папками.
  * **Плоский список (`flat`)**: компактный список файлов с относительными путями.
* **Индикаторы**:
  * Иконки статуса: `M` (изменен), `A` (создан), `D` (удален), `R` (перемещен/скопирован).
  * Бейджи строк: `+12 -3`.

---

### 8. `IgnoreManager` — Умные исключения (`.agentignore`)
* Файл хранится в `.agent-inspector/.agentignore`.
* При первом старте сканирует проект и объединяет все найденные `.gitignore`.
* Поддерживает стандартный синтаксис gitignore через библиотеку `ignore`.

## ⚙️ Полная таблица конфигурации (`settings.json`)

| Параметр | Тип | По умолч. | Описание |
| :--- | :---: | :---: | :--- |
| `agentDiff.enable` | `boolean` | `true` | Включение / отключение автоматического отслеживания правок. |
| `agentDiff.autoOpen` | `boolean` | `true` | Автоматически открывать файлы при их изменении. |
| `agentDiff.openMode` | `string` | `"diff"` | Режим открытия: `"diff"` (окно сравнения со снимком) или `"document"`. |
| `agentDiff.openLocation` | `string` | `"active"` | Где открывать: `"active"` (в текущей панели) или `"beside"` (сбоку). |
| `agentDiff.maxAutoOpenFiles` | `number` | `3` | Максимальное количество файлов, открываемых во вкладках за один раз. |
| `agentDiff.jumpToFirstChange` | `boolean` | `true` | Автоматически скроллить и перемещать курсор к первому блоку правок. |
| `agentDiff.enableHighlight` | `boolean` | `true` | Подсветка измененных строк в коде, полоски в gutter и маркеры на скроллбаре. |
| `agentDiff.burstThresholdMs` | `number` | `200` | Порог интервала (мс) между изменениями: блокирует авто-открытие при лавинах/копировании. |
| `agentDiff.maxFileSizeBytes` | `number` | `2097152` | Максимальный размер текстового файла (2 МБ) для построчного diff-анализа. |
| `agentDiff.autoArchive` | `boolean` | `false` | Автоматически архивировать шаг промпта по таймеру (по умолчанию выкл, шаг по кнопке). |
| `agentDiff.autoArchiveSeconds`| `number` | `8` | Время бездействия в секундах до авто-архивирования шага (если включено). |
| `agentDiff.treeViewMode` | `string` | `"tree"` | Режим отображения проводника: `"tree"` (иерархическое дерево) или `"flat"`. |
| `agentDiff.protectedPatterns` | `array` | `[...]` | Список glob-масок защищенных файлов (`.env*`, lock-файлы). |
| `agentDiff.ignorePatterns` | `array` | `[...]` | Игнорируемые пути (`node_modules`, `.git`, `.agent-inspector` и др.). |
| `agentDiff.debounceMs` | `number` | `300` | Задержка группировки событий файловой системы в миллисекундах. |

## 🔨 Сборка и установка

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка расширения (Production бандл через esbuild)
npm run build

# 3. Упаковка в .vsix пакет
npx @vscode/vsce package --no-dependencies

# 4. Установка в ваш Visual Studio Code
code --install-extension agent-change-inspector-1.0.1.vsix --force
```

Для вступления обновлений в силу в уже открытом окне VS Code:
> Нажмите `Ctrl+Shift+P` → выберите **`Developer: Reload Window`**.
