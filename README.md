# Agent Change Inspector (AI Diff Guard) для VS Code

Расширение для VS Code, которое автоматически отслеживает изменения файлов, вносимые AI-агентами (Antigravity, Aider, Claude Code, Cursor/Copilot background processes и др.), мгновенно открывает **Diff-предпросмотр** и помогает быстро обнаружить:
1. **Куда именно залез ИИ** (в какие файлы и директории).
2. **Какие строки были изменены** (автоматический скролл и подсветка измененных участков).
3. **Защита от нежелательных правок** (мгновенное предупреждение и кнопка отката, если ИИ изменил защищенные файлы).

---

## 🚀 Основные возможности

* **Автоматическое открытие Diff**: при изменении файла на диске открывается штатное окно сравнения VS Code (`git.openChange`).
* **Прыжок к измененным строкам**: курсор и экран автоматически прокручиваются к первому блоку правок (`workbench.action.compareEditor.nextChange`).
* **Умная фильтрация**: расширение игнорирует ваши собственные сохранения файлов в VS Code (`Ctrl+S`), поэтому реагирует **только** на внешние изменения агента.
* **Строка состояния (Status Bar)**: внизу экрана отображается `🤖 ИИ: file.ts (стр. 14-22: +8/-2)`. Клик по иконке открывает список всех недавних изменений.
* **Быстрый откат (Revert)**: если ИИ изменил то, что не должен был, можно нажать кнопку «Откатить этот файл» прямо в уведомлении или откатить все правки через меню.
* **Защищенные файлы (Protected Paths)**: можно настроить список файлов (например, `**/.env*`, `**/*.lock`, `**/auth/**`), при попытке агента изменить которые всплывает критическое предупреждение с предложением мгновенно вернуть всё назад.

## ⚙️ Настройки (`settings.json`)

Вы можете настроить поведение под свои привычки:

```jsonc
{
  // Включить / выключить авто-отслеживание
  "agentDiff.enable": true,

  // Режим открытия: "diff" (окно сравнения) или "document" (обычный редактор)
  "agentDiff.openMode": "diff",

  // Где открывать вкладку: "beside" (сбоку в сплит-экране) или "active" (в текущей группе)
  "agentDiff.openLocation": "beside",

  // Автоматически перемещать курсор и скроллить к первой измененной строке
  "agentDiff.jumpToFirstChange": true,

  // Показывать всплывающее уведомление с кнопкой быстрого отката
  "agentDiff.showNotification": true,

  // Список файлов, которые агент НЕ должен трогать (при изменении покажет тревогу)
  "agentDiff.protectedPatterns": [
    "**/*.lock",
    "**/package-lock.json",
    "**/pnpm-lock.yaml",
    "**/.env*",
    "**/protected/**"
  ],

  // Игнорируемые папки
  "agentDiff.ignorePatterns": [
    "**/node_modules/**",
    "**/.git/**",
    "**/dist/**",
    "**/build/**",
    "**/.next/**",
    "**/.agents/**"
  ],

  // Задержка группировки изменений нескольких файлов (в миллисекундах)
  "agentDiff.debounceMs": 400
}
```

## 🛠 Установка в VS Code

После сборки `.vsix` пакета выполните команду в терминале:

```bash
code --install-extension agent-change-inspector-0.1.0.vsix
```

Или в VS Code:
1. Откройте панель расширений (`Ctrl + Shift + X`).
2. Нажмите на три точки `...` в правом верхнем углу панели.
3. Выберите **«Install from VSIX...»** и выберите файл `.vsix`.
