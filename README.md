# Agent Change Inspector (AI Diff Guard & Snapshot Engine)

> **Интеллектуальная система защиты проекта, версионирования и инспекции правок AI-агентов для Visual Studio Code.**

Расширение создано для разработчиков, активно использующих инструменты генерации кода и автономных AI-агентов (**Google Antigravity, Claude Code, Aider, Cursor, GitHub Copilot CLI, Windsurf** и др.). 

Когда внешний агент модифицирует десятки файлов, разработчик теряет контроль: непонятно, какие именно файлы были затронуты, что в них изменилось, удалил ли агент что-то лишнее и как быстро вернуться к рабочей версии.

**Agent Change Inspector** берет проект под круглосуточную охрану:
1. **Мгновенно открывает измененные файлы** во вкладках с закреплением и фокусировкой на первых измененных строках.
2. **Мягко подсвечивает измененные строки** прямо в коде и на полосе прокрутки.
3. **Сохраняет физические копии (снэпшоты) файлов «ДО правок»** в структурированный каталог `.agent-inspector/snapshots/`, позволяя в любой момент заглянуть в прошлую итерацию через проводник Windows или VS Code.
4. **Группирует правки по шагам промптов** с автоматическим сворачиванием по таймеру бездействия и возможностью отката в один клик.
5. **Предоставляет двухпанельный проводник** (Дерево папок / Плоский список) с красной подсветкой удаленных файлов.
6. **Защищает критические файлы** (`.env`, lock-файлы, авторизацию) от несанкционированного изменения агентом.
7. **Управляет умным файлом исключений** `.agent-inspector/.agentignore`, автоматически собирая все `.gitignore` проекта.

## 🧩 Подробное описание подсистем и модулей

### 1. `ChangeDetector` — Детектор изменений и защита от циклов
* **Файловый наблюдатель**: Создает `vscode.workspace.createFileSystemWatcher('**/*')`, отслеживая события `onDidChange`, `onDidCreate`, `onDidDelete`.
* **Разделение правок «Пользователь vs Агент»**:
  * Слушает `vscode.workspace.onDidSaveTextDocument`.
  * При сохранении файла пользователем через редактор VS Code таймстемп фиксируется в `userSaveTimes`.
  * Если файл изменился в течение 1500 мс после сохранения пользователем (и файл ранее не отслеживался в активном шаге), событие считается пользовательским и игнорируется.
  * Если же файл **уже находится в списке активных изменений** (например, пользователь нажал `Ctrl+Z` для отмены правок агента), событие намеренно пропускается для фиксации отката.
* **Безусловная защита от рекурсивных циклов**:
  * Любые события внутри `/.git/`, `/node_modules/`, `/.agent-inspector/`, `/.vscode/` отсекаются немедленно до вызова каких-либо асинхронных операций.
* **Дебаунс и пакетирование**:
  * Все изменения собираются в `Map<string, vscode.Uri> pendingChanges`.
  * По таймеру дебаунса (`debounceMs`, по умолчанию 400 мс) пачка передается на обработку.
  * Если пачка превышает 50 файлов (массовое копирование папки), размер пачки безопасно срезается, защищая систему от зависания.

---

### 2. `GitHelper` — Git-инспекция и поддержка вложенных репозиториев
* **Поиск корня Git (`findGitRoot`)**:
  * Во многих проектах внутри монорепозитория или рабочей зоны находятся независимые подпроекты со своими каталогами `.git` (например, папка расширения `ex/`).
  * `findGitRoot(filePath, workspaceRoot)` поднимается вверх от директории файла к корню проекта, находя ближайший каталог `.git`. Все Git-команды выполняются с `cwd: repoRoot`.
* **Парсинг хунков (`getGitDiffSummary`)**:
  * Выполняет `git diff -U0 --no-color --ignore-submodules -- "<file>"`.
  * Парсит заголовки хунков вида `@@ -startOld,lenOld +startNew,lenNew @@`.
  * Формирует список диапазонов измененных строк `DiffHunkRange` (`startLine`, `endLine`, `isAddition`), точный номер первой измененной строки (`firstChangedLine`) и количество добавленных/удаленных строк (`+A/-D`).
  * Для бинарных файлов (изображения, архивы, шрифты) diff отключается.
* **Чтение чистой версии (`getFileFromGitHead`)**:
  * Выполняет `git show "HEAD:<relPath>"` с бинарным буфером (`maxBuffer: 10MB`).
  * Позволяет получить оригинальный файл до любых правок агента (даже если файл уже изменен или удален на диске).
* **Откат файла (`revertGitFile`)**:
  * Для отслеживаемых файлов выполняет `git checkout -- "<file>"` (или `git restore`).
  * Для неотслеживаемых новых файлов удаляет их с диска.

---

### 3. `ArchiveManager` — Физические снимки на диске (`.agent-inspector/snapshots`)
* **Структура каталога `.agent-inspector/`**:
  ```text
  .agent-inspector/
    ├── .gitignore          # Содержит '*\n' — полностью защищает архив от попадания в Git
    ├── .agentignore        # Правила исключений для расширения
    └── snapshots/
        ├── 2026_10_29_14_03_29/
        │   └── src/
        │       └── server.ts   # Точная копия файла ДО изменений данного шага
        └── 2026_10_29_14_15_02/
            └── ...
  ```
* **Создание снимка (`archivePreChangeFile`)**:
  * Вызывается при первом обнаружении изменения файла в рамках текущего шага.
  * Если файл уже есть в Git HEAD — извлекает его через `getFileFromGitHead` и записывает в `snapshots/<folderName>/<relativeName>`.
  * Если файла нет в HEAD (untracked), но он существовал на диске — копирует текущую дисковую версию.
  * Если в рамках текущего шага файл уже архивировался — не перезаписывает его (хранит именно первоначальное состояние).
* **Безопасная ротация архива (`cleanupOldFolders`)**:
  * Папки снимков названы по дате `YYYY_MM_DD_HH_mm_ss`, поэтому сортируются хронологически.
  * Расширение хранит последние **50 снимков на диске**. При превышении лимита самые старые папки удаляются, не затрагивая `.gitignore` и `.agentignore`. Снимки сохраняются между перезапусками VS Code!
* **Восстановление из архива (`restoreFromArchive`)**:
  * При откате шага копирует файлы из папки снимка обратно в проект, либо использует Git.

---

### 4. `HistoryManager` — Шаги выполнения промптов и авто-кулдаун
* **Текущий шаг (`currentTurnChanges`)**:
  * Аккумулирует все файлы, которые агент меняет в текущий момент.
* **Авто-архивирование шага**:
  * После каждой пачки изменений запускается таймер кулдауна (`autoArchiveSeconds`, по умолчанию 8 секунд).
  * Если в течение 8 секунд новых правок не поступает — считается, что AI завершил генерацию ответа на промпт. Шаг автоматически переносится в историю («Шаг 1: 14:05 (3 файла: +42/-8)»), текущий список очищается, а следующий промпт получит новую папку снимков.
* **Ручное управление**:
  * Кнопка «Зафиксировать шаг в архив» переносит текущие правки в историю мгновенно.
  * Кнопка «Откатить шаг» восстанавливает состояние всех файлов шага из снимка `.agent-inspector`.

---

### 5. `DiffPresenter` — Умное открытие вкладок
* **Защита от лавины вкладок (`maxAutoOpenFiles`)**:
  * Если агент изменил 50 файлов (например, установил библиотеку или скопировал шаблон), открытие 50 вкладок повесит редактор.
  * Настройка `agentDiff.maxAutoOpenFiles` (по умолчанию `5`) ограничивает авто-открытие первыми $N$ файлами. Остальные файлы аккуратно доступны в боковом проводнике правок.
* **Постоянные вкладки (`keepEditor`)**:
  * VS Code по умолчанию открывает файлы в режиме предпросмотра (заголовок курсивом), и каждая следующая вкладка заменяет предыдущую.
  * `DiffPresenter` открывает вкладки с опцией `preview: false` и выполняет команду `workbench.action.keepEditor`, чтобы все $N$ файлов открылись как полноценные постоянные вкладки.
* **Режимы открытия (`openMode`)**:
  * `'diff'` — открывает окно сравнения `git.openChange` с автоматическим переходом к первому хунку (`workbench.action.compareEditor.nextChange`).
  * `'document'` — открывает обычный файл и скроллит к строке изменения.
* **Контроль защищенных файлов (`protectedPatterns`)**:
  * При изменении файлов масок (`**/.env*`, `**/*.lock`, `**/auth/**`) выводит диалоговое окно тревоги с кнопками «Откатить изменения» и «Открыть файл».

---

### 6. `DecorationManager` — Мягкая подсветка измененных строк в коде
* При открытии любого текстового документа накладывает мягкую декорацию (`TextEditorDecorationType`) на строки, затронутые агентом:
  * Зеленоватый фон для добавленных строк (`rgba(40, 167, 69, 0.15)`).
  * Синевато-оранжевый фон для модифицированных строк (`rgba(255, 140, 0, 0.15)`).
  * Маркеры на полосе прокрутки (Overview Ruler).
  * Зеленые/оранжевые маркеры на полях номеров строк (Gutter).
* Автоматически обновляется при переключении между редакторами (`onDidChangeActiveTextEditor`, `onDidChangeVisibleTextEditors`).

---

### 7. `AgentChangesTreeProvider` & `AgentFileDecorationProvider` — Проводник правок
* **Двойное размещение**:
  1. Отдельная вкладка на Activity Bar («Правки ИИ» с иконкой робота).
  2. Панель в стандартном проводнике файлов (Explorer) слева внизу.
* **Два режима отображения (`treeViewMode`)**:
  * **Дерево (`tree`)**: полная иерархия каталогов (`src/` → `components/` → `Button.tsx`).
  * **Плоский список (`flat`)**: удобный список файлов с относительными путями.
* **Индикаторы и подсветка**:
  * Иконка статуса файла: добавлен, изменен, удален, защищенный.
  * Бейдж суммарных строк: `+12/-3`.
  * **Красная подсветка удаленных файлов**: класс `AgentFileDecorationProvider` красит удаленные файлы в проводнике в красный цвет и добавляет букву `D` (Deleted).
* **Контекстные команды элементов**:
  * Клик — открыть файл или Diff.
  * Иконка отката — вернуть отдельный файл к состоянию до правок.
  * Иконка корзины — убрать файл из списка отслеживания.
  * Иконка отката шага — вернуть весь шаг промпта.

---

### 8. `IgnoreManager` — Умные исключения (`.agentignore`)
* **Размещение**: Файл хранится в `.agent-inspector/.agentignore`.
* **Автоматическая сборка из всех `.gitignore`**:
  * При первом старте сканирует весь проект на наличие любых файлов `**/.gitignore` (включая все вложенные папки и микросервисы).
  * Корректирует относительные пути (если `.gitignore` лежит в `server/`, правило `build/` преобразуется в `server/**/build/`).
  * Формирует единый удобный файл правил.
* **Авто-миграция**: При обновлении со старых версий автоматически переносит `.agentignore` из корня проекта внутрь `.agent-inspector/`.
* **Библиотека `ignore`**: Правила работают по стандартному синтаксису Git (.gitignore).

---

### 9. `SettingsWebviewPanel` — Панель настроек
* Полноценный интерфейс настроек (открывается кнопкой-шестеренкой в заголовке панели):
  * **Блок исключений**: визуальные чипы правил `.agentignore` с возможностью удаления крестиком, поле быстрого добавления новой маски, кнопка «Пересканировать все .gitignore» и кнопка «Открыть файл в редакторе».
  * **Блок вкладок**: чекбоксы авто-открытия, выбор режима (Diff / Документ), числовой ввод лимита открываемых окон (`maxAutoOpenFiles`), авто-скролл.
  * **Блок защищенных путей**: добавление и удаление защищенных шаблонов.

---

### 10. `StatusBarManager` — Строка состояния
* Внизу экрана показывает компактную плашку:
  `🤖 ИИ: App.tsx (стр. 45-52: +14/-2)`
* При клике открывает меню быстрых действий: открыть текущий Diff, показать список измененных файлов, очистить список или временно приостановить отслеживание.

## ⚙️ Полная таблица конфигурации (`settings.json`)

| Параметр | Тип | По умолч. | Описание |
| :--- | :---: | :---: | :--- |
| `agentDiff.enable` | `boolean` | `true` | Включение / отключение автоматического отслеживания правок агента. |
| `agentDiff.autoOpen` | `boolean` | `true` | Автоматически открывать файлы при их изменении агентом. |
| `agentDiff.openMode` | `string` | `"diff"` | Режим открытия: `"diff"` (окно сравнения Git) или `"document"` (обычный редактор). |
| `agentDiff.openLocation` | `string` | `"active"` | Где открывать: `"active"` (в текущей группе вкладок) или `"beside"` (в сплит-экране сбоку). |
| `agentDiff.maxAutoOpenFiles` | `number` | `5` | Максимальное количество файлов, автоматически открываемых во вкладках за один раз (защита от лавины окон). |
| `agentDiff.jumpToFirstChange` | `boolean` | `true` | Автоматически скроллить и перемещать курсор к первому блоку правок. |
| `agentDiff.enableHighlight` | `boolean` | `true` | Мягкая подсветка измененных строк прямо в тексте файла и на полосе прокрутки. |
| `agentDiff.autoArchive` | `boolean` | `true` | Автоматически архивировать текущий шаг промпта после паузы в правках. |
| `agentDiff.autoArchiveSeconds`| `number` | `8` | Время бездействия в секундах до закрытия текущего шага и переноса в историю. |
| `agentDiff.treeViewMode` | `string` | `"tree"` | Режим отображения проводника: `"tree"` (иерархическое дерево) или `"flat"` (плоский список). |
| `agentDiff.showNotification` | `boolean` | `false` | Показывать всплывающее уведомление внизу справа при изменениях. |
| `agentDiff.protectedPatterns` | `array` | `[...]` | Список glob-масок защищенных файлов (по умолчанию: `.env*`, lock-файлы, protected). |
| `agentDiff.ignorePatterns` | `array` | `[...]` | Игнорируемые пути при поиске (по умолчанию: `node_modules`, `.git`, `.agent-inspector` и др.). |
| `agentDiff.debounceMs` | `number` | `400` | Задержка группировки событий файловой системы в миллисекундах. |

## 🔨 Сборка проекта с нуля

Если проект клонируется из репозитория:

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка расширения (Production бандл через esbuild)
npm run build

# 3. Упаковка в .vsix пакет
npx @vscode/vsce package --no-dependencies

# 4. Установка в ваш Visual Studio Code
code --install-extension agent-change-inspector-0.5.2.vsix --force
```

Для вступления обновлений в силу в уже открытом окне VS Code:
> Нажмите `Ctrl+Shift+P` → выберите **`Developer: Reload Window`**.
